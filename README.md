# Immix Protect: Trend Radar

A product-strategy trend report for Immix Protect leadership. It tracks emerging companies, technology and regulation in **video monitoring, virtual monitoring and remote guarding** first, with general security last. It covers these regions in order: **US, UK, EMEA and South Africa**. Other regions appear only when something there matters.

| File | What it is |
|---|---|
| [`docs/sources.md`](docs/sources.md) | Source list, grouped by tier and region |
| [`docs/format-and-workflow.md`](docs/format-and-workflow.md) | Cadences (daily, weekly, monthly), section structure, scoring, and the review-then-send workflow |
| [`templates/weekly-radar.html`](templates/weekly-radar.html) | Branded HTML email template for the weekly edition (email-safe inline styles) |
